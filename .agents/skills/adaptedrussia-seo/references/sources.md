# Официальные источники

Это точки входа для повторной проверки, а не навсегда зафиксированные правила. При каждом аудите открывай документы по нужной теме, проверяй актуальность, область применения и поддержку поисковой системой. В отчёте указывай точную ссылку и дату обращения; недоступный документ отмечай как непроверенный. Дата подготовки списка: 21.10.2026.

## Яндекс

- [Официальная справка Вебмастера](https://yandex.ru/support/webmaster/ru/): переходи к актуальным разделам об индексировании, robots, Sitemap, метатегах, диагностике и проверке состояния URL.
- [Яндекс Вебмастер](https://webmaster.yandex.ru/): отчёты конкретного сайта доступны только при разрешённом доступе.
- Раздел «Поиск с Алисой» открывай из актуальной справки Вебмастера; если он недоступен, не приписывай ему рекомендации Google и не придумывай требования для включения в ответы.

## Schema.org и AI-краулеры

- [Schema.org](https://schema.org/), [Schema Markup Validator](https://validator.schema.org/): словарь и синтаксис; не подтверждают eligibility поисковых rich results.
- [OpenAI crawlers](https://platform.openai.com/docs/bots): разделяй назначение OAI-SearchBot, GPTBot, ChatGPT-User по актуальной документации.
- [Google crawlers](https://developers.google.com/search/docs/crawling-indexing/overview-google-crawlers): сверяй назначение и правила конкретного агента. Для других поставщиков используй их официальную документацию, не общий список из стороннего блога.

## Проверяемость содержания

Для норм РФ используй официальное опубликование и действующую редакцию на дату проверки, например [pravo.gov.ru](https://pravo.gov.ru/), официальные сайты ведомств и конкретных университетов. Памятка вуза подтверждает локальную процедуру, но не заменяет федеральную норму. Не отправляй приватный код, персональные данные или секреты в поисковые запросы.
