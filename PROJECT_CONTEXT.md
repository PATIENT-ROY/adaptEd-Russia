# Контекст проекта

## Оптимизация главной — 21 октября 2026

- Стек подтверждён по установленным пакетам: Next.js 15.5.12, React 19.1.0, Sharp 0.34.4.
- Главная разделена на серверный `src/app/page.tsx` и клиентский `src/app/home-content.tsx`. Подсчёт гайдов остаётся на сервере, в браузер передаются только числа. First Load JS по двум последовательным production-сборкам: 433 → 371 КБ.
- Четыре изображения главной заменены версиями WebP с новыми именами. Размер исходных файлов: 4 835 726 → 244 474 байта; это не измеренная экономия сетевого трафика, поскольку production использует оптимизатор Next Image. Оригиналы сохранены.
- Метрика использует `lazyOnload`; настройки счётчика и существующая логика согласия сохранены. Очень короткие посещения могут завершиться до загрузки счётчика.
- Проверки: production-сборка, TypeScript, ESLint изменённых файлов, `git diff --check`; локальная главная и WebP отвечают HTTP 200. Подтверждён существующий кеш изображений на 30 дней, задаваемый middleware. Просмотрены WebP и desktop-скриншот в Chrome.
- Полная проверка адаптивности, мобильный Lighthouse и аналитика на production не выполнялись. Новый PageSpeed-балл не измерен. Публикации не было.
- В рабочем дереве до начала задачи уже были изменения гайдов, not-found, tsbuildinfo и документы аудита; они не относятся к этой оптимизации.
- Следующий шаг: после разрешённой публикации повторить мобильный и desktop PageSpeed; отдельно проверить работу Метрики на реальном домене. Без разрешения production не менять.
